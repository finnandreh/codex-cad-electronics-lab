# Arduino Nano 33 BLE Sense Rev2 case

Reference: [official Arduino Nano 33 BLE Sense Rev2 documentation](https://docs.arduino.cc/hardware/nano-33-ble-sense-rev2/).

The design uses the official 43.16 × 17.76 mm outline and mounting pattern,
with USB access, header openings and a broad sensor/component window. The
generated case envelope is 59.16 × 33.76 × 20.65 mm.

Recorded software checks: valid base/lid solids, case STEP readback, closed
STL meshes and zero calculated base/lid/reference collision volume. The flat
board artwork is an attributed visual reference and is excluded from exports.

Component heights, cable clearance, screws, print tolerances, RF, sensors and
physical fit have not been tested.
