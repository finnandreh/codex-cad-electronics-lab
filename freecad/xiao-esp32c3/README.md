# Seeed XIAO ESP32C3 case

Reference: [official Seeed XIAO ESP32C3 documentation](https://wiki.seeedstudio.com/XIAO_ESP32C3_Getting_Started/).

The source uses the nominal 21 × 17.8 mm board layout with cradle rests,
USB/antenna access and lid openings. The generated case envelope is
37 × 33.8 × 20.65 mm.

Recorded software checks: valid base/lid solids, case STEP readback, closed
STL meshes and zero calculated base/lid/reference collision volume. Vendor
reference material is excluded from manufacturing exports.

The flat reference does not model component heights. External-antenna
placement, retention, cables, print tolerances, RF, thermal behaviour and
physical fit have not been tested.
