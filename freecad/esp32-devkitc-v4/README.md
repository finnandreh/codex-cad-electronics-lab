# ESP32-DevKitC V4 case

Reference: [official Espressif ESP32-DevKitC V4 documentation](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32/esp32-devkitc/user_guide.html).

The source uses the official 48.26 × 27.94 mm PCB outline and 6.04 mm module
antenna overhang, with rests, connector access, header openings and antenna
clearance. The generated case envelope is 48.26 × 43.94 × 20.65 mm.

Recorded software checks: valid base/lid solids, case STEP readback, closed
STL meshes and zero calculated base/lid/reference collision volume. The flat
vendor image is a visual reference, not a component-height model, and is not
included in case exports.

Board retention, connectors, print tolerances, thermal and RF behaviour have
not been physically tested.
