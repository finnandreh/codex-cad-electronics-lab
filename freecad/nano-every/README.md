# Arduino Nano Every case

Reference: [official Arduino Nano Every documentation](https://docs.arduino.cc/hardware/nano-every/).

The source uses the official 43.18 × 17.78 mm PCB dimensions with mounting
supports, USB access and header/lid openings. The generated case envelope is
59.18 × 33.78 × 20.65 mm.

Recorded software checks: valid base/lid solids, case STEP readback, closed
STL meshes and zero calculated base/lid/reference collision volume. The board
representation is a simplified reference and is excluded from case exports.

Component heights, connector fit, screws, print tolerances, thermal behaviour
and physical fit have not been tested.
