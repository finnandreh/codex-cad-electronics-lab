# Teensy 4.1 case

Reference: [official PJRC Teensy 4.1 documentation](https://www.pjrc.com/store/teensy41.html).

The source uses the official 60.96 × 17.78 mm board dimensions, the published
width tolerance and a 1.57 mm PCB reference. It provides rests, USB/microSD
access and lid/header openings. The generated case envelope is
76.96 × 33.78 × 20.65 mm.

Recorded software checks: valid base/lid solids, case STEP readback, closed
STL meshes and zero calculated base/lid/reference collision volume. Vendor
reference imagery is excluded from manufacturing exports.

Populated-header height, retention, cables, microSD access, screws, printing,
thermal behaviour and physical fit have not been tested.
