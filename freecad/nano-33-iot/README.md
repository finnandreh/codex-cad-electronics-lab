# Arduino Nano 33 IoT case

Reference: [official Arduino Nano 33 IoT documentation](https://docs.arduino.cc/hardware/nano-33-iot/).

The source reconciles the official 43.16 × 17.77 mm board drawing and four
1.66 mm mounting holes with USB access, board supports and lid/header
openings. The generated case envelope is 59.16 × 33.77 × 20.65 mm.

Recorded software checks: valid base/lid solids, case STEP readback, closed
STL meshes and zero calculated base/lid/reference collision volume. The flat
Arduino artwork conveys board position but does not model component heights;
it is excluded from manufacturing exports.

Real-board fit, cable access, screws, print tolerances, RF, thermal behaviour
and physical fit have not been tested.
