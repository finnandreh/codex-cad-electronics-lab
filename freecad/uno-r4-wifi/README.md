# Arduino UNO R4 WiFi enclosure concept

Reference: [official Arduino UNO R4 WiFi documentation](https://docs.arduino.cc/hardware/uno-r4-wifi/).

The 86 × 67.34 × 22.65 mm concept has 2.4 mm walls/floor, four board support
positions, four lid posts, USB-C/DC/Qwiic access, header openings, ICSP/ESP
access, an LED-matrix window, reset-tool access and five ventilation slots.
The official board assembly was used as an attributed design reference and is
excluded from case manufacturing exports.

Recorded software checks: valid base/lid solids, two-solid STEP readback,
closed STL meshes at Z=0 and zero calculated base/lid/reference collision
volume. One STL required welding coincident tessellation vertices; no holes
were filled.

The real board, cable overmoulds, plugs, screws, printing tolerances, thermal
behaviour and physical fit have not been tested.
