# Sloped desktop control box

This desktop variant uses a 140 × 90 mm footprint with a sloped control
surface. The recorded overall height is 55 mm. It includes internal supports,
a cable opening, two 16 mm switch openings and two 8 mm indicator openings.

Recorded software checks: one valid base solid, one valid lid solid and zero
calculated base/lid intersection. The supplied neutral and mesh exports are
case-only.

This is concept geometry. Viewing angle, stability, controls, cables, screw
selection, print tolerances and electrical use have not been physically
tested.
