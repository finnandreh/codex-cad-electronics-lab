# Vented wall control box

This variant adds wall-mounting lugs and a vented lid to the original
140 × 90 × 50 mm enclosure. The recorded outer base bounds including the
mounting geometry are 174 × 90 × 50 mm. The lid remains 140 × 90 × 3 mm and
contains the control-panel openings.

Recorded software checks: one valid base solid, one valid lid solid and zero
calculated base/lid intersection. The STEP and STL files contain generated
case geometry only.

This is concept geometry. Wall fasteners, load, ventilation performance,
environmental protection, tolerances and electrical suitability have not been
physically tested.
