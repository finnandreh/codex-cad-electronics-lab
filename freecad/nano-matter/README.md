# Arduino Nano Matter case

Reference: [official Arduino Nano Matter documentation](https://docs.arduino.cc/hardware/nano-matter/).

The source reconciles the official 43.18 × 17.78 mm board drawing and STEP
reference with mounting/rest geometry, USB and antenna-side access and lid
openings. The generated case envelope is 43.18 × 33.78 × 18.65 mm.

Recorded software checks: valid base/lid solids, case STEP readback, closed
STL meshes and zero calculated base/lid/reference collision volume. Vendor
reference geometry is excluded from manufacturing exports.

Physical retention, component/cable clearance, print tolerances, RF and
thermal behaviour have not been tested.
