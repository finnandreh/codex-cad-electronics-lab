# Arduino Nano ESP32 case

Reference: [official Arduino Nano ESP32 documentation](https://docs.arduino.cc/hardware/nano-esp32/).

The source reconciles the official 43.18 × 17.78 mm board outline and official
STEP reference with mounting points, USB access, header openings and lid
clearances. The generated case envelope is 59.18 × 33.78 × 20.65 mm.

Recorded software checks: valid base/lid solids, two-solid case STEP,
closed base/lid STL meshes and zero calculated base/lid/reference collision
volume. Vendor reference geometry is excluded from manufacturing exports.

Purchased-board fit, connector/cable fit, screws, print tolerances, RF and
thermal behaviour have not been physically tested.
