# Demonstration videos

Final public video masters are attached to the GitHub release rather than
stored in the Git history. Captions live with the corresponding CAD project.

The canonical public channel is
[Finn Andre Hotvedt on YouTube](https://www.youtube.com/@finnandrehotvedt6974).
The project links in the repository README may point to scheduled videos until
their configured publication time has passed.

The videos show actual native-application work and generated results. They do
not establish physical fit, electrical function, manufacturing readiness or a
repeatable one-prompt timing benchmark.
