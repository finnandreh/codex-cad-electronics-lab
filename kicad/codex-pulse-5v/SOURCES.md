# Sources

Circuit reference:

- Texas Instruments, **TLC555 LinCMOS Timer**, revision SLFS043K,
  January 2026: <https://www.ti.com/lit/ds/symlink/tlc555.pdf>
- Product information: <https://www.ti.com/product/TLC555>

Application in this project: regulated 5 V astable timing using the standard
eight-pin PDIP pinout.

The source document itself is not redistributed here. The repository includes
the generated schematic, PCB and bounded verification evidence.
